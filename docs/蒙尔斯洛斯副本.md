# 蒙尔斯洛斯副本 · 设定与实现文档

## 一、神灵
蒙尔斯洛斯（Melslos）——原初神格，佩迦神话体系之**时间之神**。
形态：无定形的白色之海（世界海）。神职：剥夺 · 轮回 · 时间。

## 二、阶段流程（已实现）
1. **靠近触发**：白色之海中走向神像（z≤-32），听到「凡人，请你领教海洋的魅力。」
2. **十四觉位剥夺**（纯演出，约 29s）：世界→听觉→嗅觉→视觉→触觉→温觉→压觉→
   动觉→衡觉（深浅颠倒）→痛觉→味觉→情觉→记忆觉→自我觉→存在觉，
   每剥夺一觉，雾白一分、声轨弱一分、旁白一句。终点：「你成了空白之人。成了绳索。」
3. **授枪**：剥夺尽头，祂把枪塞进你手里——
   「你连自己都留不住的时候，祂把枪塞进了你手里。」
4. **本体战**：面对时间海的女人形态（程序几何体拼装：袍/躯干/首/双臂/光轮）。
   - 三道**追踪光束**缓慢咬向玩家方位 + 每 12s 一轮**扫射光幕**（持续 4.5s）
   - 被击中：视觉被夺，纯黑 10 秒，复活回原位（累计死亡计数显示）
   - **空白·伊莉尔斯**：真枪。按住「开火」全自动射击（约 8 发/s），准星命中本体
     则白掉一层（-1 神性）。弹匣 42 发，打空后祂自动续上下一份（0.9s）。
   - 目标：打掉 **100 层白**（100 HP）。祂的白色随血量渐褪。
5. **终局**：100 层尽失，祂站在原地，像一件已经给出去的东西。
   奖励「**时力**」——子弹时间 20s（长按开火键发动，冷却 45s），
   写入 SharedPreferences 永久保留，跨副本可用。

## 三、核心法则（设定）
- 深浅颠倒：深层在上、浅层在下（剥夺第 8 幕旁白点出）
- 空白即永生：十四觉位尽失者化为绳索，在轮回中永续
- 祂即时间：蒙尔斯洛斯就是时间本身
- 希望之刑：「最残酷的不是永远爬不到，而是每一次你都以为是最后一次」

## 四、关键台词（已植入）
- 「凡人，请你领教海洋的魅力。」
- 「最残酷的不是永远爬不到——」「——而是每一次，你都以为是最后一次。」
- 「光穿过了你。祂取走了你的视觉。」
- 「祂把下一份塞进你手里。」（换弹）
- 「海退了。你夺走了祂的一部分时间。」（终局）

## 五、武器 · 空白·伊莉尔斯
- 枪身那层白不是漆，是祂握过之后留下的
- 伤神性不伤身体：只能打祂；对人、对物、对海——连响都闷
- 42 发弹匣，无弹尽概念：祂还愿意给，你就能打
- 打满一百段，祂就把最后一块还像自己的地方整个交给你
- 她没教你赢。她只是没拦你打到她里面去。

## 六、武器工程规格（v1.1.1 生效，键名不可改）

| 字段 | 值 |
|---|---|
| 内部 ID | weapon_blank_ibliss |
| 类型 | 文件型武器（表现形式是一份被逐段读取的介绍，不是弹道武器） |
| 判定 | 仅对神性目标生效；打在非神性目标上无任何反馈（无弹痕/无击中音/无 miss 提示） |
| 单轮容量 | 42 段；扣完自动续下一份，**不存在弹尽状态**；终止条件 = 祂被念空（100 段） |
| 轮末 | 世界静音 0.3s（祂吸气）→ 下一份 42 段 |
| 每 25 段 | 「世界漏一拍」：全部运动冻结 0.35s |
| HUD | 只显示「供给中 · 第 X 轮 (n/42)」，**不显示会归零的弹药数**，无 DPS/伤害数字 |

### 存档键（SharedPreferences "ibliss"，改键名=老存档失效）
| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| ibliss:has | bool | false | 是否持有（键实现为 "has"） |
| ibliss:pages_read | int | 0 | 已读段数 0–100（单一事实源） |
| ibliss:cycle | int | 1 | 当前供给轮次 |
| ibliss:delivered | bool | false | 递枪演出是否已播放（阶段二末解锁） |

### 事件契约
武器脚本只发 `OnPageRead` 事件；BOSS 脚本只监听事件、不直读 pages_read。
当前 Java 单文件实现中等价于：updateBoss 命中后调 onPageRead()，pages_read 为唯一事实源，bossHp = 100 − pages_read。

### 解锁时机
阶段一/二文件不可读（表现为尚未递枪）；递枪演出结束 → delivered=true → 解锁；
未念到的段落是空白，当前正在念的这一段是实的（战斗内以"白层消退"呈现）。
